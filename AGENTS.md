# Grupee agent guide

Read [SETUP.md](SETUP.md) before running local services, changing environment variables,
running migrations, using staging, or deploying production. It is the single source of truth for
local, staging, and production operations.

Read the package-level `AGENTS.md` before changing `backend/`, `frontend/`, or `admin/`. Those
files define the implementation invariants for their package.

Keep operational instructions in `SETUP.md`; keep product capabilities and technical choices in
`README.md`.
